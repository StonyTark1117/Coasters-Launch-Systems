# Dependency and asset provenance

All Launch Systems gameplay code, models and tests are independently authored. The Gradle wrapper originates from the NeoForge ModDevGradle MDK via the sibling Fourth Dimension checkout and retains its Apache 2.0 notices. Runtime libraries are resolved from their publishers and are not bundled. The sibling project and inspected Engineered release informed API usage; no third-party gameplay implementation or assets were copied.

The addon is MIT licensed. Minecraft textures referenced by original model JSON remain provided by the installed game. Manufacturer names describe mechanism concepts; no manufacturer assets are distributed.
