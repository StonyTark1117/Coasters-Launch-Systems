## Session procedure

1. Created a local packaged dedicated-server run directory, accepted its EULA, and started the normal packaged server task:

   ```sh
   JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew runServer -PlsPackaged --offline --console=plain --no-daemon --max-workers=2
   ```

   The server listened on port 25565 and reported `Done (2.860s)! For help, type "help"`.
2. Started the normal packaged client task under a local Xvfb display:

   ```sh
   JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew runClient -PlsPackaged -PlsValidation --offline --console=plain --no-daemon --max-workers=2
   ```

   Used its normal title-screen Multiplayer flow and entered `127.0.0.1:25565` through Direct Connection. The dedicated-server log recorded `Dev joined the game` at 09:46:48; the primary client reached the spawned world.
3. Kept Dev connected. Started the separate packaged observer task under a second Xvfb display:

   ```sh
   JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew runObserver -PlsPackaged -PlsValidation --offline --console=plain --no-daemon --max-workers=2
   ```

   Used the same normal Multiplayer → Direct Connection flow. The server recorded `Observer joined the game` at 09:48:00, while no departure was recorded for Dev. The observer reached the spawned world.
