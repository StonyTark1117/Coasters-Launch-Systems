# Read-only Free Spin geometry diagnosis

`VehicleGeometryDiagnostics` is gated by `coasterslaunchsystems.validation=true` and permission level 2. It registers only `/lsdiagnose geometry <native-chassis-uuid> <source-controller-pos>`. The command reads native identities, poses, collision shapes, loaded world cells, and the observed accepted contact. It does not call the motion provider (which may refresh authority), alter forces, dispatch/capture/resume, mutate blocks, add loading tickets, or call the controller route cache/migration method. It constructs a separate DirectedRoute and peeks the contact cache without stale-entry cleanup. Contact age is reported explicitly. Source-controller epoch/authority behavior is unchanged.

The report includes per-block transformed collision-box corners, world AABBs and exact separating-axis intersections against fixed world shapes. These are current static geometry intersections, not a history of swept contacts and not solver contact callbacks. It separately reports chassis linear and angular velocities, COM, tirePoint world arm, directed tangent and translation/angular/combined point-speed projections using the same formula as RideTransfers.train. A zero current intersection count cannot rule out a prior transient collision or prove that a future route is clear.

The first implementation called transferRoute(), which can populate controller caches and migrate old fields. Parent review caught that before the accepted diagnostic invocation; the accepted SHA046993ce build uses pure DirectedRoute.between. An initial server restart omitted the validation flag and registered no command; rides corrected the owned launcher and preserves that history. No gameplay acceptance is claimed by either preparation attempt.
